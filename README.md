# LOOKBEN — Sitio web v2

Sitio estático para publicar directamente en GitHub Pages. No requiere instalación ni compilación.

## Archivos
- `index.html`: página principal.
- `estudio-seguridad.html`: página Estudio de Seguridad.
- `styles.css`: identidad visual, diseño adaptable y animaciones.
- `app.js`: menú, ventanas de servicios, checklist, formulario y apariciones progresivas.
- `assets/`: logo, QR e ilustraciones técnicas SVG.

## Publicación en GitHub
1. Abrí el repositorio `lookben-web`.
2. Entrá en la pestaña **Code**.
3. Elegí **Add file → Upload files**.
4. Arrastrá los archivos de esta carpeta y la carpeta `assets` completa.
5. Conservá la estructura: HTML, CSS, JS y README en la raíz; recursos dentro de `assets/`.
6. Confirmá el reemplazo de los archivos existentes.
7. En el mensaje del commit escribí `LOOKBEN v2 - evolución visual`.
8. Seleccioná **Commit changes**.

No subas la carpeta contenedora `LOOKBEN_GitHub_v2`; subí su contenido.
